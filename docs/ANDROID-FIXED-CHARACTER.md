# Android 合成台 2：人物资产第一版

从原合成台历史点「保存为人物母版」，或在合成台 2 导入本机照片。填名字、检查身份图、完整全身母版和形体快照，确认后保存。选人物版本，勾选要改的服饰、姿势、背景、光影或画风，填写目标或选择图，然后检查实际发送的图和提示词，再点击生成。原合成台继续使用旧流程和旧历史。

## 独立数据

- 人物资产包含名称、描述、ID 与版本列表。每个版本保存确认时间、身份图、全身母版、完整现有形体快照、可选来源历史 ID。身份图可与母版相同。添加版本不会替换旧版本。
- 独立的 IndexedDB 键存合成台 2 草稿、人物资产和历史；大图及缩略图以内容 SHA-256 存放。没有共享原合成台的可变草稿。确认存盘和图片提交为事务。删除原历史不影响新人物资产；重用历史仍指向当时的版本、图、模型参数和实际 Prompt。
- 图片默认本机存储；生成时通过现有安卓 OpenAI 编辑桥上传已明示的输入。Key 继续由原生保管，本功能的数据结构没有 Key 字段。超过单张编辑图片大小限制的合法生成图可以制作本地编辑副本，不修改原图。
- 第一版未接入手动备份导出、清理未被引用的图、生成候选母版、多视角、多姿势母版。卸载前不能依赖既有备份保存合成台 2 数据。

## 编辑语义

原合成台从身份、服饰、姿势的分工参考重新组合人物。合成台 2 先明确保留母版里同一个人，只修改本次标出的属性。七个 Prompt 模块固定按参考规则、身份、形体、服装、姿势、风格、输出组装。形体快照补充母版，不反向改造母版。同图复用时编号共享；附加图仅允许背景、光影或画风。保持姿势参考的可见范围（半身不补全）。例如只换装，母版与身份同图时：

> 编辑图1中的同一人物，不重新设计。只修改：服饰与配饰；未选的属性保持母版原样。  
> 保持图1的人物身份；在身份维度，参考图1的脸型、五官、发型、发色和基础肤色。  
> 图1是身体比例、骨骼长度、身体体积与局部轮廓的视觉基准。  
> 只采用图2的服装与配饰，包括款式、颜色、层次与面料。  
> 保持图1的动作、镜头与构图，本次不另设。背景、光影、画风同样保持。  
> 保持自然解剖、接触点、透视及服装褶皱。

上述摘取了关键行。最终发送的全文和有序参考图在生成前及旧记录中均可查看。此方法不是 3D 身体锁定；人物一致性需用相同模型和参考图对照实测。
