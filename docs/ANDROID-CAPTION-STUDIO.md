# 安卓批量配文工作台

## 使用
1. 在合成台点「批量配文」，从本地生成记录多选、预览、调整顺序。也可从当前生成结果或某张历史卡片进入并预选该图。合成台仍一次生一张图，工作台不改自动生成或三个参考图库。
2. 默认是公众号、独立配文、智能推荐、标准长度、每图三条。切换到统一配文或完整图文后，数量指整组候选方案数。高级设置默认折叠。视觉与文本模型分别填写。
3. 确认预计图片及方案数后才会开始。OpenAI 模式复用安卓设置里的本机密钥：视觉模式发送最长边至多 1,024 px 的压缩图和文本，Prompt 模式只发送文字，不代表实际看过图。本地模板不会联网，风格和文本变化受模板库限制。
4. 批次中可暂停派发、继续、取消、重试失败、编辑／选择、复制、标记使用、收藏。重新生成追加版本。未知结果先核对厂商用量，再手动重试；不承诺后台持续运行。进程重启，从「批量配文 → 历史批次」打开，等待项可手动继续。
5. 完整文章可混排预览。系统分享支持文案、原图、TXT、Markdown 及 ZIP。ZIP 的 Markdown/HTML 用相对路径引用原图。没有自动发布。原图只保留在原有生成记录里；旧记录被清除或被历史容量淘汰后，批次文字仍可看，缺失原图的 ZIP 不会生成残缺文件。

## Android 边界
配文屏幕使用独立非导出的原生 Activity。现有 Capacitor 页面只提供生成历史索引及按需的图片字节，不嵌入配文界面，不新申请相册权限。选择源是生成历史，不混入服饰、姿势、人像参考图库。安卓端只有 OpenAI 的文本与视觉协议被接入；其他已有厂商生图能力不变。配置不会自动把生图模型切到文案模型或反向写回。

每个批次用独立原子 JSON 文件记录配置、顺序、ID、真实 Prompt 与已有摘要、状态及各候选版本。分析缓存键包含结构版本、厂商、模型、图 ID、版本及压缩图片指纹。缓存命中仍读取本机缩图校验，不重新上传。原图不写入配文持久化。系统分享临时文件用专用 FileProvider 授权；导出结构不序列化内部配置、密钥、提示词或分析缓存。新配文历史不纳入现有生图备份。

## 验收
- 真机：进原合成台，确认图库、手势、折叠区、输入及生成照常。再进配文确认原生页面导航、返回、所选顺序和缩略图。至少在最低版本 Android 10 与当前安卓机分别确认。
- 先用本地模板走三种模式，操作排序、编辑、重开、分享，并解压 ZIP 检查按顺序命名和 HTML／Markdown 相对路径。
- 使用自己的测试 Key 与不含敏感内容的图片手动验证一张，再验证 20 × 3、限流及断网。暂停后无新付费阶段，后台不启新任务。杀进程重开，已完成结果仍在、中断请求须手动确认后再重试。核对同图换风格时模型用量不会再产生识图请求。
