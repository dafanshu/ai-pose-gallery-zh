# 安卓版离线图库包

安卓 APK 不携带桌面图库的第三方素材。可以用已有的 `ai-pose-gallery-zh` 完整目录，在电脑上制作个人素材包，再一次性导入手机。不需要打开 Cloudflare Access、不需要架私有服务，打包也不会联机下载外站图片。

## Windows 上制作

1. 在安卓分支的项目目录打开 PowerShell。需要 Python 3.9+（建议用仍受支持的版本）；Pillow 用于转换桌面图库的 WebP 等本地素材。
2. 在 PowerShell 运行以下命令。第一个路径是**已有完整图库**，不是仅包含代码的工作区。该目录中应有 `data`、`img`、`thumbs`。

   ```powershell
   py -m pip install Pillow
   py .\scripts\export-android-gallery.py 'D:\ai-pose-gallery-zh' "$env:USERPROFILE\Downloads\role-studio-gallery.json"
   ```

3. 核对控制台列出的人像、服饰、姿势数量，把生成的 `role-studio-gallery.json` 复制到手机「下载」。导出器不覆盖旧文件；重新打包时请使用不同文件名或移走旧包。
4. 手机打开「角色合成台」，从任一图库槽位的「导入素材包」入口，通过系统文件选择器选此 JSON。随后仍在合成台选择「人像」「服饰」「姿势」，进入相应图库；额外「参考图」才从相册添加。导入不改变生成记录、已有配方和 API Key。

## 数量、清晰度和取用边界

- 默认最多每类 100 张，按分区/类别轮流取样；可追加 `--per-kind 200`，但单包仍限 40 MiB、最多 600 张。达到大小上限时，导出项数可能更少。它不是复制整个 GB 级图库。
- 默认将图片最长边缩至不超过 768 像素。可追加 `--edge 1024` 提高清晰度；不会放大原图。优先读取可用的本地原图，找不到时尝试本地预览或缩略图。
- 仅有外链的条目、丢失或无效的文件、标为敏感的服饰和姿势不进入素材包。不会将外站链接、Exif、账号配置或 API Key 写入包。图库包仍含图片本身，请核对素材来源和许可，只在自己的设备间传递，不要上传到公开仓库、Actions 或分享渠道。
- 选中的素材作为本地图片进入配方与生成记录；仅在明确点击生成后，所选图片才发送给当前配置的厂商。手机端导入图库与导入历史备份是分开的入口。
