# 安卓版离线图库 ZIP

安卓 APK 不携带桌面图库的第三方素材。用已经在电脑上的完整图库生成 ZIP，复制到手机导入。不需要放开 Cloudflare Access 或部署服务，导出脚本也不会下载只有外链的图片。

## Windows 上制作

在安卓分支的项目目录打开 PowerShell。需要 Python 3.9+ 和 Pillow。将第一个路径指向含 `data`、`img`、`thumbs` 的**现有完整图库**，不是仅包含代码的工作区。

```powershell
py -m pip install Pillow
py .\scripts\export-android-gallery.py 'D:\ai-pose-gallery-zh' "$env:USERPROFILE\Downloads\role-studio-gallery.zip"
```

核对控制台列出的人像、服饰、姿势数量。把生成的 `role-studio-gallery.zip` 复制到手机「下载」，**不用解压**，也不需要另复制图片目录。App 打开「合成台」，点人像、服饰或姿势的「从图库选择」，再导入 ZIP。不在任一图库槽位把相册作为入口；只有额外参考图使用系统相册。

导入时 App 把 ZIP 作为自己的离线副本。预留足够空间容纳一份新 ZIP（替换时旧版会保留到检查成功）。确认导入后可离线打开 App 使用，建议在电脑另留一份 ZIP，供重装后重新导入。图库和「导出与还原备份」互相独立；已选中的图片会单独随配方或历史保存，替换/移除素材包不清掉它们。

## 包结构与上限

```text
role-studio-gallery.zip
├── manifest.json   # ID、类别、名称、标签，不含图片字节
├── thumbs/         # 按页加载的独立 JPEG 缩略图
└── images/         # 点选时读取的独立 JPEG 参考图
```

- 默认导出所有合规且可读的本地索引条目，不再按每类 100 项抽样。不把外站链接、EXIF、配置或 API Key 写入包。缺失/无效本地图、仅有外链和已标记敏感的服饰、姿势依然跳过并计数。素材许可按各来源执行，不要上传到公开仓库、Actions 或群聊。
- 整包上限 2 GiB，最多 10,000 项。超限时导出明确失败，不会留下半截包；可选 `--per-kind 1200` 减少范围。不要手改 ZIP 结构或重新压缩。
- 缩略图最长边 320 像素，参考图默认 1024 像素；可用 `--edge 1280` 提高参考图尺寸（不会放大原图）。优先使用本地原图，找不到时才退到本地预览或缩略图。
- 重新导出请使用不同文件名，脚本不会覆盖已有文件。旧 `.json` 小包的导出方式仍保留给旧版使用，新版推荐 ZIP。手机不会在浏览图库时向外站请求图片；只有明确点击生成才会把所选参考图发送给本次使用的厂商。
