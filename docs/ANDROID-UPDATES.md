# 安卓公开更新

已放弃 R2 私有下载方案。公开更新由 GitHub Releases 提供，不要求 Cloudflare、GitHub 登录或下载口令；手机需能访问 GitHub。只有指定仓库的安卓分支会自动发布。每个版本使用单独的预发布标签 `role-studio-android-v<versionCode>`，不改变 Harness 的 Release 或仓库的 Latest 标记。APK 与 `update.json` 是仅有的自定义发布附件，不发布图库、历史记录、API Key、签名私钥或签名配置。

原有 CI 先签名、检查固定证书指纹及应用 ID，然后才上传签名产物。发布任务使用独立的 GitHub 权限，不接触签名凭据；在两个附件都上传后公开版本。

旧版（包括私有更新试验版 1021）要先手动覆盖安装首个公开更新版本，无需卸载或本地签名。之后在「厂商连接设置 → 检查更新」，点「检查更新 → 下载并安装」，首次可能需要对角色工作台开放「安装未知应用」权限。安装始终由系统界面确认，不后台自动安装。

Android 只链接固定 GitHub 仓库及 GitHub 下载域名，只接受标签与清单一致且比当前安装版本高的 APK。下载安装前检查大小、SHA-256、包名、版本和与当前安装匹配的签名。安装过程保留应用数据，不改变模型服务商设置。
